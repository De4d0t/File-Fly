# 🌐 موقع FileFly الرسمي (Landing Page)

موقع تعريفي احترافي وفخم لتطبيق **FileFly** مبني باستخدام **Next.js 14 (App Router) + React + Tailwind CSS**.

---

## 🚀 التشغيل محلياً (Local Development)

للتشغيل والمعاينة على جهازك:

```bash
cd website
npm install
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

---

## ⚡ البناء والتأكد من الإنتاج (Production Build)

```bash
npm run build
npm run start
```

---

## ☁️ خطوات الرفع والنشر المباشر على Vercel (مجاناً وبشكل فوري)

لربط الموقع بـ Vercel مع التحديث التلقائي في كل مرة تدفع فيها كوداً جديداً إلى GitHub:

1. ادخل إلى حسابك في [Vercel.com](https://vercel.com).
2. اضغط على **"Add New..."** ثم **"Project"**.
3. اختر مستودعك: **`De4d0t/File-Fly`**.
4. في شاشة الإعدادات، أهم خطوة هي:
   * ابحث عن خيار **Root Directory** واضغط **Edit**.
   * اختر مجلد: **`website`** ثم اضغط **Continue**.
5. سيتعرف Vercel تلقائياً على أن المشروع هو **Next.js**.
6. اضغط **Deploy**!

🎉 في أقل من دقيقة واحدة، سيعطيك Vercel رابطاً رسمياً مباشراً وسريعاً جداً، مع شهادة أمان SSL مجانية، وأي تحديث تدفعه لـ GitHub سيقوم Vercel بإعادة بنائه ونشره تلقائياً!
